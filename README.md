# One Line, One Chill — entry

A program/v1 entry for the make.fun "One Line, One Chill"
bounty. `main.py` writes one sentence to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The sentence:

> When the search party found the cabin, the dinner was still warm, the chairs were still rocking, and every mirror in the house was facing the wall.

The mirrors are the part nobody explains. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
